# Direction d'interface
Les skills frontend-design, frontend-ui-engineering et ui-ux-pro-max guident le travail. Les deux recherches locales du design system ont renvoyé des structures marketing et une typographie enfantine, inadaptées à la première : elles ne sont pas retenues. Les principes d'accessibilité, de navigation visible et de sobriété restent utiles.

L'interface sert la prochaine séance de travail. Pas de page marketing. Cinq destinations : Aujourd'hui, Documents, Fiches, Entraînement, Synchronisation. Une navigation textuelle repliable sur petit écran ; les textes longs restent dans une largeur de lecture limitée. Le format ivoire quadrillé est réservé aux fiches conformément au prompt Notion.

Tokens : surface #F4F7FA ; papier #FFFDF6 ; texte #233650 ; secondaire #506078 ; action #214C70 ; définition #28786B ; alerte #A33238 ; relation #78608D. Police sans serif embarquée egui, corps 16, titre 30, sous-titres 22, métadonnées 13. Espacements de 4/8/16/24/32 ; boutons d'au moins 44 pixels. Aucun mouvement décoratif. Le statut est toujours écrit en toutes lettres et jamais communiqué par la couleur seule.

Plan : navigation fixe, état de connexion visible, contenu à défilement unique. Aujourd'hui : prochaine question, matières avec nombre réel de fiches et de questions, puis contenus à valider. Documents : filtre et liste avec transcription éditable. Fiches : aperçu coloré, sources et export. Entraînement : une question, réponse puis correction et autoévaluation SM-2. Synchronisation : accès privé, journal réel, commandes explicitement nommées.
